## VoiceAgentRAG: Solving the RAG Latency Bottleneck in Real-Time Voice Agents Using Dual-Agent Architectures

📂 方向：RAG + AI Agent
👤 作者：Jielin Qiu | Jianguo Zhang | Zixiang Chen et al.
📅 日期：2026-03-02
🔗 PDF：https://arxiv.org/pdf/2603.02206v1
🔗 ArXiv：https://arxiv.org/abs/2603.02206

💡 **摘要**：We present VoiceAgentRAG, an open-source dual-agent memory router that decouples retrieval from response generation. A background Slow Thinker agent continuously monitors the conversation stream, predicts likely follow-up topics using an LLM, and pre-fetches relevant document chunks into a FAISS-backed semantic cache. A foreground Fast Talker agent reads only from this sub-millisecond cache, bypassing the vector database entirely on cache hits.

## RAPO: Expanding Exploration for LLM Agents via Retrieval-Augmented Policy Optimization

📂 方向：AI Agent + RAG
👤 作者：Siwei Zhang | Yun Xiong | Xi Chen et al.
📅 日期：2026-03-03
🔗 PDF：https://arxiv.org/pdf/2603.03078v1
🔗 ArXiv：https://arxiv.org/abs/2603.03078

💡 **摘要**：Agentic RL has shown remarkable potential in LLM-based agents. However, existing methods rely on pure on-policy exploration, restricting discovery of new reasoning perspectives. RAPO introduces hybrid-policy agentic rollout by retrieving relevant step-level trajectories from historical off-policy data to expand exploration space during RL training.

## Beyond Task Completion: Revealing Corrupt Success in LLM Agents through Procedure-Aware Evaluation

📂 方向：AI Agent
👤 作者：Hongliu Cao | Ilias Driouich | Eoin Thomas et al.
📅 日期：2026-03-03
🔗 PDF：https://arxiv.org/pdf/2603.03116v1
🔗 ArXiv：https://arxiv.org/abs/2603.03116

💡 **摘要**：Current benchmarks evaluate whether a task was completed, not how. PAE formalizes agent procedures as structured observations and evaluates along axes of Utility, Efficiency, Interaction Quality, and Procedural Integrity, applying multi-dimensional gating that disqualifies corrupt outcomes.

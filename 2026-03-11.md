## Memex(RL): Scaling Long-Horizon LLM Agents via Indexed Experience Memory

📂 方向：Agent Memory
👤 作者：Zhenting Wang | Huancheng Chen | Jiayun Wang et al.
📅 日期：2026-03-04
🔗 PDF：https://arxiv.org/pdf/2603.04257v1
🔗 ArXiv：https://arxiv.org/abs/2603.04257

💡 **摘要**：Memex introduces indexed experience memory to overcome the finite context window bottleneck for long-horizon LLM agents. Unlike truncation or summarization, Memex preserves past evidence as a lossless indexed store for efficient selective retrieval.

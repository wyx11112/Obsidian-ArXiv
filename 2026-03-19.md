## TRUST-SQL: Tool-Integrated Multi-Turn Reinforcement Learning for Text-to-SQL over Unknown Schemas

📂 方向：Data Warehouse Agent ⭐
👤 作者：Ai Jian | Xiaoyun Zhang | Wanrou Du et al.
📅 日期：2026-03-17
🔗 PDF：https://arxiv.org/pdf/2603.16448v1
🔗 ArXiv：https://arxiv.org/abs/2603.16448

💡 **摘要**：TRUST-SQL addresses Text-to-SQL under Unknown Schema (hundreds of noisy tables) by formulating it as a POMDP where the agent actively identifies relevant schema subsets via tool-integrated RL. Achieves SOTA +30.6% improvement on unknown schema benchmarks.

## Chronos: Temporal-Aware Conversational Agents with Structured Event Retrieval for Long-Term Memory

📂 方向：Agent Memory
👤 作者：Sahil Sen | Elias Lumer | Anmol Gulati et al.
📅 日期：2026-03-17
🔗 PDF：https://arxiv.org/pdf/2603.16862v1
🔗 ArXiv：https://arxiv.org/abs/2603.16862

💡 **摘要**：Chronos decomposes dialogues into subject-verb-object event tuples with datetime ranges and entity aliases, enabling temporal-aware memory retrieval for multi-hop time-sensitive queries. Achieves 95.60% on LongMemEvalS (SOTA).

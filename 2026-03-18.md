## D-MEM: Dopamine-Gated Agentic Memory via Reward Prediction Error Routing

📂 方向：Agent Memory
👤 作者：Yuru Song | Qi Xin et al.
📅 日期：2026-03-15
🔗 PDF：https://arxiv.org/pdf/2603.14597v1
🔗 ArXiv：https://arxiv.org/abs/2603.14597

💡 **摘要**：D-MEM is biologically inspired memory architecture using Reward Prediction Error routing to decouple short-term interaction from cognitive restructuring. A Fast/Slow system with Critic Router achieves O(1) fast-access for routine inputs vs. deep restructuring for high-surprise inputs, solving O(N²) write-latency in A-MEM.
